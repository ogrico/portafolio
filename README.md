# portafolio

Portafolio web de Geovany Rico (og.rico): proyectos con demos, hitos en empresa, sobre mí y contacto.

Sitio: https://ogrico.github.io/portafolio/

Por ahora es una maqueta en un solo archivo (`index.html`) con proyectos de ejemplo. Los tokens de marca están al inicio del bloque `<style>` y los proyectos en la lista `PROYECTOS` del script.
